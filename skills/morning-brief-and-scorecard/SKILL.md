# Morning brief and scorecard

## Morning brief

Read today's notes in `/workspace/lending-team/daily/<date>/`: `ghl.md`, `affiliate.md`, `outbound.md`, `borrower.md`. Skip a missing file and say which one is missing.

Write under 150 words, in this order:

```
Needs your yes
1. [agent] [to whom]: [what, one line]
2. …

Yesterday: [n] new leads, [n] partner sign-ups, [n] referrals, [n] calls booked, [n] replies waiting

Broken: [one line each, or "nothing"]

Today: [time] [who], [one line of prep]
```

Group similar approvals, for example "12 partner check-ins (list)". Give the full list only if the owner asks.

## Approvals

- "approve 1, 3", "skip 2", "edit 4: …", "approve all".
- Write the result to `approved/<date>.md`.
- Send each agent its own approved items in one message.
- Anything not approved by the next morning goes into the next brief once, then drops off, and is noted in the scorecard.

## Friday scorecard

One screen:
- **Partner funnel, this week and the four-week average:** contacted → interested → signed → first referral → referrals.
- **Borrower funnel:** new leads → quick app completed → handed off → funded (as reported by the owner's team in GHL).
- **Past clients:** touched, repeat loans, borrower referrals.
- **Health:** workflow errors, deliverability, approvals that waited.
- **Three wins, three stalls, one focus for next week.**

Use numbers from GHL and the cold email tool only. If a number isn't available, say so; don't estimate.
